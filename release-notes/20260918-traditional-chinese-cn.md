# Codeflai 更新日志 — 0.27.0 / 2026-09-18

## 概览

界面新增繁体中文，设置里的「语言」也从并排按钮改成了下拉。

## 新增功能

- **需求背景：** 此前界面只有英语和简体中文两种。用繁体中文的用户只能将就看简体，而且看到的是逐字转换那种别扭的说法——「设置」「会话」「文件夹」并不是繁体中文界面里的习惯用词。
- **功能描述：** 界面新增**繁體中文**，覆盖全部文案：设置、侧边栏、新建会话菜单、快捷提示词、更新与关机对话框、系统通知。它是按台湾用语习惯独立翻译的，不是简体的逐字转换——是「設定」「工作階段」「資料夾」「儲存庫」「終端機」，不是「設置」「會話」「文件夾」。
- **使用场景：** 习惯繁体中文界面的用户，现在可以整个应用都用繁体中文。
- **操作路径：** 设置 → 通用 → 「语言」→ 选择「繁體中文」。

## 体验优化

- **「语言」改成下拉选择。** 原先三种语言并排成一行按钮，加上第三种之后就挤不下了，于是和上面的「主题」一样改成下拉。**每一项仍然用它自己的语言书写**（English / 简体中文 / 繁體中文），所以万一切到了看不懂的语言，你照样能在下拉里认出自己那一项、切回来。

## 特别说明与指引

- **语言只覆盖界面文案。** 命令行工具的查找提示、会话的报错信息，以及**已经生成好的会话标题**，都保持它们产生时的语言，切换语言不会把它们重写一遍。
- **默认仍是英语**，不跟随系统语言。选好的语言会记住，下次打开还是它。
- **升级不会改变你现在的语言。** 之前选的是简体中文就还是简体中文，之前是英语就还是英语。

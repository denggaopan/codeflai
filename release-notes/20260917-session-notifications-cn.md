# Codeflai 更新日志 — 0.26.0 / 2026-09-17

## 概览

会话跑完时，Codeflai 现在会弹一条系统通知，任务栏和 Dock 上同时显示未读标记——不用再守着窗口。

## 新增功能

- **需求背景：** 把窗口切走或最小化之后，agent 什么时候跑完就无从知道了。侧栏的加粗标题和未读计数只在你看得见窗口时才管用，于是等一个长任务往往变成隔几分钟切回去瞄一眼。
- **功能描述：** agent 跑完一轮、或者会话自己退出时，系统弹出一条通知，标题是会话名、正文是所属项目。任务栏（Windows）和 Dock（macOS）同时显示未读标记。点这条通知会把 Codeflai 叫到最前面，并直接切到那个会话。
- **使用场景：** 交代完任务就去写文档、开会，或者干脆最小化窗口等一个长时间的构建。
- **操作路径：** 设置 → 通用 → 「会话完成时通知」。默认开启。

## 特别说明与指引

- **窗口就在你面前时不会弹通知。** 那种时候侧栏的加粗标题已经在告诉你了，再弹一条只是噪音。
- **自己停止或删除会话不会收到通知。** 按钮是你按的，不需要系统再说一遍。
- **重启或重连不会补发旧通知。** 每次启动重绘的历史输出是旧消息，不是新消息。
- **Windows 显示一个圆点，macOS 显示数字。** Windows 的任务栏角标只能放图片、画不了数字；而侧栏本来就精确到每个项目的未读数，所以任务栏只负责回答「有没有」。macOS 的 Dock 原生支持文字，就直接显示总数。
- **被系统挡下的通知是静悄悄的。** Windows 的「专注助手」和 macOS 的「勿扰模式」都会拦截通知，而且不会告诉应用。如果一条都收不到，先去系统设置里确认 Codeflai 的通知是允许的。

# Codeflai 更新日志 — 0.37.0 / 2026-11-16

## 概览

在飞书 / Lark 里添加同事时，现在可以指定他只能用哪一个项目。这位同事以后给机器人发指令，不用再写项目名。

## 新功能亮点

### 添加同事时指定项目

- **需求背景：** 以前每位同事都能在你电脑上的任何一个项目里开会话，而且每条指令都必须写对项目名，写漏了机器人就回「找不到项目」。
- **功能描述：** 添加同事前先选好一个项目，这位同事就只能在这个项目里开会话：
  - 发指令时不用写项目名，直接说要做什么；
  - 消息里即使提到了别的项目名，也只当成任务内容，会话仍然开在指定的项目里；
  - 回复别的项目的会话时，机器人回「没有权限」，内容不会交给那个会话。
- **使用场景：**
  - 只负责某一个项目的同事，在群里 @Codeflai 说一句「修一下登录页的报错」就能开工；
  - 想让外部协作者帮忙处理一个项目，又不想让他在你的其他项目里开会话。
- **操作路径：** 设置 → Lark → 成员，在「添加同事」按钮旁的下拉里选一个项目，再点「添加同事」，把生成的配对码发给对方。下拉保持「所有项目」就和以前一样，不做限制。

## 功能优化

- **一眼看清每个人的范围：** 成员列表里，受限的同事名字旁会标出「仅限 某项目」；项目后来被移出 Codeflai 的，会标出「项目已移除」。此前列表里只有名字和添加日期。
- **配对码写明它给的范围：** 给同事的配对码旁会显示「仅限 某项目」或「所有项目」，发出去之前可以再确认一遍。

## 特别说明与指引

- **这个限制管的是会话开在哪个项目，不是 agent 能碰到什么。** 会话仍然以你的账户、不经确认地运行，同事在指令里要求它去读写这台电脑上的其他文件，它是做得到的。请只添加你信得过的人。
- **要更换或取消某位同事的限制：** 重新选好项目（或选「所有项目」），再生成一个配对码让他发一次，以他最新用掉的那个配对码为准。配对码请私聊发送。
- **指定的项目被移出 Codeflai 后**，这位同事的指令会被拒绝，并提示他联系你重新添加，不会改到别的项目里去执行。
- **你自己（所有者）不受限制**，仍然需要在消息里写出项目名。此前添加的同事也不受影响，和升级前一样可以使用所有项目。
- **给同事指定了项目之后，如果退回到旧版本**，旧版本读不了新的成员信息，Lark 的设置需要重新填写。
- 升级到这个版本**不会**重启正在运行的会话。

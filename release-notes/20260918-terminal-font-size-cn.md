# Codeflai 更新日志 — 0.26.3 / 2026-09-18

## 概览

终端字号可以自己调了，另外修好了 macOS 上关掉窗口后再打开会卡住的问题。

## 新增功能

- **需求背景：** 终端字号一直是固定的。屏幕大的时候嫌字小看着累，屏幕小或者想一眼看到更多输出的时候又嫌字大，只能忍着。
- **功能描述：** 设置里多了一个「终端字号」下拉，从 10 到 24 共十档。选中即生效，所有打开着的终端一起变，不用重启、也不用切换会话。
- **使用场景：** 接上外接显示器时调大一点，或者在笔记本屏幕上想让一屏装下更多日志时调小一点。
- **操作路径：** 设置 → 通用 → 「终端字号」。

## 问题修复

- **macOS：关掉窗口后再从程序坞打开，窗口不再卡住。** 此前在 macOS 上关掉 Codeflai 的窗口（应用仍在后台运行），再点程序坞图标重新打开，新窗口会一直停在加载状态、什么也做不了，只能强制退出重开。

## 特别说明与指引

- **只能调字号，不能换字体。** 终端里那些用方块字符拼出来的图案（比如 Claude 启动时的 logo），需要按字体的精确字宽做像素级对齐才不会出现细缝。换字号时这套计算会自动重算，换字体就得重新推导一遍，所以这版只放开字号。
- **改字号会让终端重新排版。** 每行能放下的字数变了，正在运行的全屏界面（Claude、Codex 这类）会整屏重绘一次，这是正常的。
- **选好的字号会记住**，下次打开还是它。

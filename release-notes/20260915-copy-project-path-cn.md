# Codeflai 更新日志 — 0.25.0 / 2026-09-15

## 概览

项目菜单新增「复制项目目录地址」，一键把项目所在目录的完整路径放进剪贴板，不用再从侧栏念着路径手敲一遍。

## 新增功能

- **新增「复制项目目录地址」。** 点项目右侧的 ⋯ 打开菜单，它就在「打开项目文件夹」下面一项。点一下，项目目录的完整路径（例如 `E:\projects\app`）进入系统剪贴板，可以直接粘进另一个终端的 `cd`、粘进文件对话框的地址栏，或者贴给同事。
- **复制成功会有明确提示。** 剪贴板本身不会给任何反馈，所以复制后侧栏顶部会出现一条提示，把刚复制的路径完整写出来——既确认复制成功了，也让你在粘贴之前先核对一眼路径对不对。这条提示会一直留到你点 × 关掉它。

## 特别说明与指引

- 复制的是**项目目录**的地址，也就是你添加项目时选的那个文件夹，不是某个会话的 worktree 目录。
- 路径以主进程记录的为准：如果你当初选的是一个快捷方式或带短名的路径，复制出来的会是它实际指向的完整路径。
- 现在项目菜单共 6 项（仓库带远程地址时）：新建会话 / 在 VS Code 中打开项目 / 打开项目文件夹 / 复制项目目录地址 / 打开 Git 仓库 / 从列表中移除。

# Codeflai 更新日志 — 0.23.2 / 2026-09-10

## 概览

这一版专门整理了「设置」界面：原来是一列到底的长条，现在改成左右两栏，左边是分类菜单，点一下就跳到对应的设置项。

## 新功能亮点

### 设置界面的分类菜单

- **需求背景：** 设置里的东西越攒越多——开机自启动、主题、语言、会话类型、版本更新、关于——全挤在一个窄窗口里从上排到下。想改其中一项，得从头翻一遍；「会话类型」里再展开那 5 个可选的 agent CLI，下面的内容就只能靠滚了。
- **功能描述：** 设置窗口改成左右两栏。左边是四个分类：**通用**、**会话类型**、**更新**、**关于 Codeflai**，点哪一项右边就滚到哪里；反过来，你滚到哪一段，左边也会跟着高亮，两边永远对得上。窗口本身也比原来宽了将近一倍。
- **使用场景：** 想直接改某一项设置的时候，不用再一路翻找。
- **操作路径：** 侧栏底部的齿轮按钮 → 左侧菜单点选分类。

## 功能优化

- **分类更集中：** 主题和语言现在和开机自启动、显示快捷提示词栏一起放在「通用」里，四项常用偏好一屏看完，不再分散在窗口的上下两头。
- **窗口更宽：** 设置窗口加宽了，每行的名称和右侧开关不再挤在一起，「会话类型」那张开关表格也看得更舒展。
- **滚动条跟随主题：** 设置里的滚动条以前是系统默认的浅色样式，在深色主题下相当扎眼；现在它和界面同色，平时只是一条不起眼的空槽，鼠标移进设置窗口时才浮现出滑块。
- **齿轮按钮不再抢眼：** 鼠标移到侧栏底部的设置按钮上时，原来会亮起一圈紫色描边，看上去像是要执行什么不可逆的操作；现在只是轻轻提亮一下。

## 特别说明与指引

- **左边是快捷跳转，不是分页：** 右边始终是完整的一整页，点菜单只是帮你滚过去。就算点错了分类，继续往下滚一样能看到想找的设置项，不存在「必须点对才看得到」的情况。
- **每次打开都是同一个起点：** 重新打开设置时，左侧菜单总是回到「通用」，「更多 agent CLI」也保持收起——和以前的行为一致。
- **设置项本身没有变化：** 这次只调整了它们的摆放位置和外观，每一项开关的含义、默认值和你已经保存的选择都原样保留。

# Codeflai 更新日志 — 0.27.1 / 2026-09-18

## 概览

这一版专门修克隆 Git 仓库时"卡住"的问题：克隆过程现在有实时进度、随时可以取消，卡住时也会明确报错而不是一直转下去。

## 新增功能

### 克隆时可以随时取消

- **需求背景：** 以前一旦点下「克隆并打开」，整个对话框就锁死了——关闭按钮变灰，按 Escape 没反应，点背景也关不掉。碰上慢的或者连不上的仓库，你除了干等没有任何别的办法，最长要等满十分钟。
- **功能描述：** 克隆进行时多了一个**「取消克隆」**按钮。点它会立刻结束克隆，连同它在后台建立的连接一起断掉，已经下载的那部分文件也会被清理干净。
- **使用场景：** 地址填错了、仓库比想象中大得多、或者等了一会儿发现网络就是不通——任何你想中途退出的时候。
- **操作路径：** 添加项目 → 「克隆 Git 仓库」→ 开始克隆后，状态文字右边就是「取消克隆」。

### 克隆时能看到实时进度

- **需求背景：** 以前整个过程只有一句「正在克隆仓库，可能需要几分钟…」，从头到尾一个字都不变。一个大仓库正常下载和一个彻底卡死的克隆，看起来完全一样，你没法判断该继续等还是该放弃。
- **功能描述：** 克隆时会显示一条**进度条**，下面跟着 Git 自己实时输出的那一行——包含当前在做什么、完成了多少、已经下载了多大、以及当前速度。
- **使用场景：** 克隆大仓库时判断"还要多久"，或者一眼看出下载速度是不是不正常。
- **操作路径：** 同上，开始克隆后自动显示。

## 问题修复

- **修复了克隆可能无限期卡住、界面看起来像死机的问题。** 现在只要连续两分钟没有任何进展，就会明确报错停下来，而不是一直转到十分钟超时。
- **修复了克隆失败后没法直接重试的问题。** 以前失败会在磁盘上留下半个仓库，再点一次克隆会直接提示"目标已存在"，你必须自己去文件夹里把它删掉才能重来。现在失败或取消后那个文件夹会被自动清理，重试就是再点一次的事。

## 特别说明与指引

- **进度那一行是 Git 自己输出的英文，不随界面语言变化。** 上面的状态文字和按钮仍然是你选的语言。这是有意保留的——Git 原文里的阶段名称、数量和速度比任何转述都准确。
- **进度百分比会来回跳，这是正常的。** Git 把克隆分成好几个阶段（清点、压缩、下载、整理），**每个阶段都从 0% 重新数**，所以你会看到进度条在过程中归零几次。下面那行文字会告诉你当前在哪个阶段。
- **如果你的网络需要代理，请单独给 Git 配一次。** 这是克隆卡住最常见的原因：Git **不读** Windows 的系统代理设置，浏览器能正常打开的地址，Git 可能完全连不上而且不报错。给你常用的代码托管站点单独配置即可，例如：

  ```
  git config --global http.https://github.com.proxy http://127.0.0.1:你的端口号
  ```

  按站点配置而不是全局配置，可以让公司内网的 Git 服务器继续直连、不受影响。

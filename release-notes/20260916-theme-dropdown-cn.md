# Codeflai 更新日志 — 0.25.3 / 2026-09-16

## 概览

主题从「深色 / 浅色」两个按钮换成了下拉菜单，并新增三套熟悉的编辑器配色：Visual Studio Dark、Abyss、Monokai。换主题会同时换掉整个窗口和里面的终端。

## 新增功能

- **多了三套主题。** **Visual Studio Dark** 是 VS Code 默认深色那身中性灰，**Abyss** 是近乎全黑的深海军蓝，**Monokai** 是那套偏暖的橄榄灰配青绿紫橙。加上原来的 **Dark** 和 **Light**，现在一共五套。
- **主题改成下拉选择。** 五个选项不再是一行按钮排得下的，而且这个列表以后还会继续长。原来的两套排在最前面，顺序不变。
- **换的是整扇窗，不只是界面。** 侧栏、对话框、终端背景与光标、原生标题栏按钮的配色一起跟着换，不会出现一半新一半旧。
- **每套主题的状态色都是自己那一套。** 运行中 / Done / 警告 / 危险这几个圆点和徽章，在新主题里用的是该配色自家的绿紫黄红，而不是把深色主题的颜色硬搬过去。

## 特别说明与指引

- **升级后主题不变。** 之前用深色就还是深色，用浅色就还是浅色，什么都不用重新设置。
- **主题和以前一样按窗口记住**，重启后自动恢复，和语言、侧栏宽度存在一起，不进会话状态文件。
- **终端里跑的程序自己的颜色不受影响。** 换的是终端的背景、前景和选区色；agent 或 shell 输出里自带的 ANSI 颜色仍由那个程序决定。
- 三套新主题都是深色的，系统滚动条、原生下拉这些窗口部件也会按深色绘制；只有 **Light** 会切到浅色。

# Codeflai 更新日志 — 0.30.0 / 2026-10-08

## 概览

项目菜单新增「删除所有会话」，一次清掉一个项目下的全部会话，不用再逐个点开会话菜单删除。

## 新增功能

- **新增「删除所有会话」。** 点项目右侧的 ⋯ 打开菜单，它在「从列表中移除」的正上方。点一下会先弹出确认框，写明要删除的是哪个项目的多少个会话；确认后，这些会话按侧栏里的顺序逐个停止并删除，正在运行的也会被停掉，项目本身留在列表里。
- **有未提交改动的 worktree 会被保留。** 每个会话走的都是和单独删除完全一样的检查：如果某个会话的 worktree 里还有未提交的改动，这个会话不会被删除，仍留在列表里；删完之后会有一条提示告诉你有几个会话因此被保留。先提交或丢弃那些改动，再单独删除它们即可。
- **项目没有会话时该项不可点。** 菜单项仍然显示，只是灰色的。

## 特别说明与指引

- 「删除所有会话」和「从列表中移除」是两回事：前者删掉会话、项目留下；后者把项目从列表移走、会话记录一并消失，但磁盘上什么都不动。
- 删除会话会移除它的 worktree 目录，但**分支永远不会被删除**，这一点和单独删除会话时一样。
- 现在项目菜单共 7 项（仓库带远程地址时）：新建会话 / 在 VS Code 中打开项目 / 打开项目文件夹 / 复制项目目录地址 / 打开 Git 仓库 / 删除所有会话 / 从列表中移除。

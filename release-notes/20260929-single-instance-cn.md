# Codeflai 更新日志 - 0.29.3 / 2026-09-29

## 概览

修复同时开着两个 Codeflai 窗口时，后打开的那个把快捷提示词栏、主题、语言等设置显示为默认值的问题。现在再次启动 Codeflai 不会再开出第二个窗口，而是把已经打开的窗口带到最前面。

## 修复内容

0.29.1 和 0.29.2 两次升级后，都有用户发现快捷提示词栏的开关被关闭、设置看起来被清空。这次查清了真正的原因：不是升级，而是同一时间有两个 Codeflai 在运行。典型情形是开启了「开机自启动」：开机后 Codeflai 已经自动打开，随后又点了一次桌面或任务栏上的快捷方式。第二个 Codeflai 读不到已保存的设置，只能按默认值显示，在它里面做的修改也不会保存，而你看到的正是这个窗口。设置本身一直安好。

从这一版开始，Codeflai 同一时间只会运行一个。再次启动它时不会再打开第二个窗口，而是把正在运行的那个窗口带到最前面；如果它被最小化了，会先恢复出来。

## 更新后如何生效

升级到 0.29.3 后如果再遇到设置显示为默认值的情况，先看看是不是还开着一个旧版本的窗口：完全退出所有 Codeflai 窗口再打开一次即可恢复。0.29.2 加入的「设置暂时无法读取」提示仍然保留，作为其他意外情况的兜底。

## 问题反馈

如果更新后再次启动 Codeflai 没有把已打开的窗口带到前面，或者设置仍然显示为默认值，请在 https://github.com/denggaopan/codeflai/issues 提交问题。

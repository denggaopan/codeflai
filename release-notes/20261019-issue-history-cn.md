# Codeflai 更新日志 — 0.34.0 / 2026-10-19

## 概览

项目操作菜单新增「Issue 处理记录」，自动处理 issue 每一轮的结果都能翻回来看，包括那些已经被自动删掉的会话。

## 新功能亮点

- **需求背景：** 自动处理 issue 时，没有可处理的 issue 的那一轮会把会话自动删掉，启动失败的那一轮也不会留下会话。无人值守跑了一夜之后，侧栏里看不出跑了几轮、空转了几轮、为什么有一轮没起来。
- **功能描述：** 按时间倒序列出这个项目自动处理过的每一轮：什么时候开始、用的哪个 agent、结果如何——认领了哪条 issue（如「issue#42 Fix login crash」）、没有可处理的 issue 而删除了会话、因 worktree 有改动而保留了会话、启动失败及原因，或者已结束但没有回报结果。对话框开着时，新的结果会实时出现在列表里。
- **使用场景：** 早上回到电脑前，想知道昨晚自动处理领了哪几条 issue、空转了多少次；或者发现某个项目一直没有新会话，想看看是不是每一轮都启动失败了。
- **操作路径：** 点击项目行右侧的「⋯」→「Issue 处理记录」。

## 特别说明与指引

- **只记录本版本之后的轮次**，更新之前跑过的不会出现在列表里。
- **每个项目保留最近 50 轮**，更早的会自动移出。
- 这一项**始终可用**：即使项目已经没有远程仓库、或所选 agent 已在设置里关闭，仍然可以查看以前的记录。
- Qwen Code 会话头部的全放行警告，对当前版本的 Qwen Code 是准确的：它已经支持 Codeflai 传入的全放行参数。较旧的版本可能仍会忽略该参数，这时警告会比实际情况更保守。

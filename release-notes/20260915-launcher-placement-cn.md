# Codeflai 更新日志 — 0.25.1 / 2026-09-15

## 概览

修复侧栏底部项目的「新建会话」菜单被切掉的问题。项目多到侧栏出现滚动条时，靠底部那几个项目的菜单只露得出上半截，下面的会话类型被压在设置按钮那一条后面，看不见也点不到。现在菜单会自己往上展开。

## 问题修复

- **修复了底部项目的「新建会话」菜单被遮挡的问题。** 此前这个菜单不管在哪一行都固定朝下展开，而它必须待在侧栏的项目列表区域里——于是越靠底部的项目，被切掉的部分越多。列表里开启的会话类型越多（比如在设置里打开了 Gemini、Copilot 这些），被切掉的条目也越多。现在菜单会看这一行上下各剩多少地方：底部的项目改为向上展开，整个菜单连同全部条目都留在可见范围内。
- **上下都挤不下时，菜单改为可以在内部滚动。** 比如把窗口拉得很矮的时候，此前多出来的条目就直接没了；现在菜单会缩到能放下的高度，剩下的条目在菜单里滚动就能看到。
- **菜单开着时滚动项目列表不再错位。** 现在它会跟着重新选择朝上还是朝下；如果你把它所属的那一行滚出了可见范围，菜单会自己关掉，而且不会把列表猛地拽回原来那一行。

## 特别说明与指引

- 项目不多、侧栏没有滚动条时，菜单仍然朝下展开——那种情况下下方本来就有地方，行为和以前一样。
- 项目的 ⋯ 菜单本身一直是这个行为，这次是把「新建会话」菜单对齐到同样的规则，两者不再各行其是。
- 操作方式没有任何变化，仍然是点项目右侧的 ⋯ → 新建会话。

# Codeflai 更新日志 — 0.26.1 / 2026-09-17

## 概览

修好了 0.26.0 里点通知没反应的问题，并去掉了任务栏上那个未读小圆点。

## 问题修复

- **点击通知现在会真的把 Codeflai 叫到前面。** 0.26.0 里点通知是完全没反应的——窗口不上来，会话也不切。原因是通知弹出后，应用没有留住它，系统层面的那条通知在后台被回收掉了，连带着「被点击」这件事再也传不回应用；整个过程不报任何错，所以从外面看就像点了个寂寞。现在通知会被留住直到你处理它，离开一段时间再从通知中心点回来也有效。

## 功能优化

- **去掉了任务栏上的未读圆点。** 此前 0.26.0 会在任务栏图标右上角画一个小圆点表示有未读。侧栏的加粗标题和每个项目的未读数已经把这件事说清楚了，通知本身也会提醒你，所以那个圆点是多余的一层。macOS Dock 上的未读数字一并去掉。设置里的「会话完成时通知」开关从此只管通知这一件事。

## 特别说明与指引

- **通知本身的行为没有变。** 什么时候弹、什么时候不弹（窗口在你面前时、你自己停掉的会话、重启后重绘的历史输出）都和 0.26.0 一样。
- **如果 0.26.0 你已经装了，直接装这版覆盖即可**，设置里的开关状态会保留。

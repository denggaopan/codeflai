# Codeflai 更新日志 — 0.23.1 / 2026-09-10

## 概览

这一版把会话的「收工」和「提醒」两件事做对了：结束一个会话时它真的会停下来，而不是只从列表里消失；未读提醒也只在 agent 真正跑完一轮时才亮。会话还可以按你自己的习惯拖动排序。

## 新功能亮点

### 停止会话

- **需求背景：** 之前只能「归档」一个会话。归档只是把它从默认列表里隐藏起来，它的 agent 还在后台继续跑、继续改 worktree 里的文件，而且带着全放行权限——你看不见它，它却还在动。
- **功能描述：** 会话菜单里的「归档」换成了「停止」。停止会真正结束这个会话的进程，并把它记为已停止。磁盘上什么都不动：worktree 保留，分支绝不删除，会话记录也留在列表里。点一下那一行就能恢复它，恢复时会接着上次的对话继续。
- **使用场景：** 一个任务告一段落、你想让机器安静下来的时候。它和「删除」的区别是：停止随时可以恢复并续上对话，删除是不可逆的。
- **操作路径：** 会话行右侧的选项按钮 → **Stop**。因为这会打断 agent 正在跑的那一轮，每次都会弹一次确认。只有正在运行或正在创建的会话才有这一项。

### 拖动排序会话

- **需求背景：** 会话只能按创建时间排列，项目里攒了七八个之后，想找的那个总在中间。
- **功能描述：** 直接拖动会话行就能重新排序，顺序立即保存，重开窗口后还在。停止或恢复会话都不会打乱你排好的顺序。
- **使用场景：** 把当前最要紧的几个会话拖到顶部，或者把相关的几个排在一起。
- **操作路径：** 按住会话行上下拖动即可。会话不能拖到别的项目下（它的 worktree 就在原来那个项目里）；搜索或状态筛选生效时拖动会暂时关闭，因为筛过的列表不是完整顺序。

## 功能优化

- **提醒更准：** 未读提醒（标题加粗）现在只在 agent **跑完一轮**时才亮——连续三秒安静、且没有待完成的后台 agent。此前只要终端有任何输出就算未读，而 agent 界面的转圈动画和计时器一直在刷新，等于「只要它在跑就一直提醒你」，真正值得看的那一刻反而被淹没在里面。命令行会话不会自己刷新界面，所以它的任何输出仍然算未读；会话退出也一律提醒。
- **菜单更好认：** 会话选项菜单的「重命名 / 停止 / 删除」三项前面都加了图标，和项目菜单保持一致，扫一眼就能找到要点的那一项。
- **筛选更简单：** 去掉了「显示范围（未归档 / 已归档 / 全部）」这个筛选项。停止一个会话后它的状态就是「已停止」，用状态筛选里的 **Stopped** 就能只看已收工的会话——原来那两个筛选其实在问同一件事。

## 特别说明与指引

- **原来归档过的会话会怎样：** 升级后它们会正常出现在会话列表里（不再被隐藏），状态保持原样。如果其中某个还在运行而你并不想让它跑，用新的「停止」结束它即可。
- **停止后再恢复，屏幕是干净的：** 停止会真正结束进程，所以恢复时是一个全新的终端，停止之前的输出不会回来——但对话本身会接着上次继续。如果你需要保留屏幕上的内容，直接切到别的会话就行，不要停止它。
- **退出 Codeflai 依然不会打断会话：** 这一点没有变化。关窗、崩溃、就地升级都不影响正在跑的会话，下次打开会重新接上；只有你主动停止、删除会话、把项目移出列表，或者重启机器才会真正结束它。启动时，已停止的会话不会被自动拉起。

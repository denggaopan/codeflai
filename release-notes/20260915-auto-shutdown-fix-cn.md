# Codeflai 更新日志 — 0.24.1 / 2026-09-15

## 概览

修复 0.24.0 的自动关机：它此前几乎永远不会触发。现在只要 agent 都干完活了，机器就会自己关掉，不用你先手动停会话。

## 问题修复

- **修复了自动关机不触发的问题。** 此前它判断的是「会话是否还开着」，而 agent 会话只要你跟它说过话，就会一直保持在运行中，直到你手动停掉——于是「机器自己关机」的前提变成了「你已经回到电脑前把所有会话都停了」，而那正是这个功能最没用的时刻。现在它按侧栏显示的状态判断：显示 **Done**（已完成、在等你输入）的 agent 不再阻止关机。
- **修复了无人值守时倒计时被拉长的问题。** 十秒倒计时以前是一秒一跳地数，而窗口在后台时系统会大幅降低这类计时的频率，十秒可能被拉成十分钟，对话框上的秒数也对不上真实时间。现在倒计时按真实时刻计算，无论窗口是否在前台都是十秒。
- **修复了电脑休眠后可能立刻关机的问题。** 如果倒计时期间机器睡了过去，醒来时会重新给你完整的十秒，而不是屏幕一亮就关机。

## 特别说明与指引

- **什么会阻止关机**，以侧栏里那一行显示的状态为准：

  | 侧栏状态 | 是否阻止关机 |
  | --- | --- |
  | **Running**（agent 正在干活） | 是 |
  | **Starting…**（终端还在启动） | 是 |
  | 开着的 PowerShell / 命令提示符 / Shell 会话 | 是 |
  | **Done**（agent 已完成，等你输入） | 否 |
  | **Stopped**、**Path missing**、**Error** | 否 |

- **开着的 shell 会让机器一直不关。** shell 永远不会显示 Done——它停在提示符上，无法说明背后是不是有构建在跑。所以用完的 shell 会话记得停掉；反过来，想临时阻止机器关机，留一个 shell 开着就行。
- **agent 空闲就会进入倒计时。** 如果你只是在看结果、没有继续输入，超过检查间隔后同样会弹出十秒倒计时——点「取消关机」即可，这也会顺手关掉自动关机开关。
- 开关和频率的用法没有变化，你已保存的选择原样保留。

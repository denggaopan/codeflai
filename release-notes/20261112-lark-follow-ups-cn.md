# Codeflai 更新日志 — 0.36.0 / 2026-11-12

## 概览

在飞书 / Lark 群里派出去的活，现在可以直接在群里接着聊：agent 会把它的问题、结果或卡住的原因发回群里，你回复一句，它就接着干。

## 新功能亮点

### 在群里回答 agent

- **需求背景：** 以前 agent 跑完一轮，群里只会收到一句「Claude 停下了，可能在等你回复，请到 Codeflai 查看」。你不知道它在问什么，在群里回复又会被当成一条新指令、多开一个会话，只能走回电脑前去终端里打字。
- **功能描述：** 回复这个会话里的任意一条消息（你发的指令，或机器人的任何一条回复），并且 @Codeflai。你的回复会作为一行「[Lark 回复 · 你的名字] 内容」输入到那个正在运行的会话里，机器人回复「已转给 Claude」。回复里带的图片也会一起交给 agent。agent 正忙时，这句话会排在它后面，和你在键盘上打字一样。
- **使用场景：**
  - agent 问你「导出成 JSON 还是 CSV？」，你在手机上回一句「CSV」；
  - 看到结果后想再改一点，直接在同一个对话里补一句，不用重新发起。
- **操作路径：** 在飞书 / Lark 里对机器人的回复点「回复」，输入 @ 选中机器人，再写上你的话发出。

### agent 主动告诉你它的状态

- **需求背景：** 以前 Codeflai 只能根据「三秒没有输出」来猜 agent 是做完了、在提问还是卡住了，猜错是常有的事。
- **功能描述：** 现在 agent 每跑完一轮都会明确告诉 Codeflai 它的状态，Codeflai 原样转进群里：
  - 需要你拍板时：「Claude 在问你：……」，一次只问一个具体的问题；
  - 做完时：「Claude 完成了：……」，附上改动的文件；
  - 卡住时：「Claude 卡住了：……」，说明卡在哪里。
- **使用场景：** 派完活去忙别的，回来看群消息就知道它到底需要你做什么。
- **操作路径：** 无需设置，从飞书 / Lark 开的新会话自动生效。

## 功能优化

- **不开窗口也能收到：** agent 的这三种回报在 Codeflai 窗口关着时也会发到群里。此前「跑完一轮」的回复必须开着 Codeflai 窗口才会发。
- **回复挂在最新的那条下面：** 你回答过之后，机器人的后续回复会挂在你那条回答下面，一问一答连成一串。此前所有回复都挂在最初那条指令下面。
- **提示更明确：** 没收到回报时的提醒改成了「可能在等你回复。回复这条消息并 @我 可以接着说」。此前这句话只能让你去 Codeflai 里看。

## 特别说明与指引

- **群里回复必须 @Codeflai。** 没有开通 `im:message.group_msg` 权限时，飞书只会把 @ 机器人的消息发给它。
- **只有白名单里的人可以回答**，规则和派活时一样；Codeflai 关着时发出的回复同样不会执行。
- **已经停止的会话不会被群里的回复叫醒。** 从飞书开的会话不会自己停下，停了就是有人在 Codeflai 里结束了它。这时机器人会说明会话已停止；要继续，请在 Codeflai 里点开它恢复，或者重新 @Codeflai 发起。
- **回复里的内容只会被当成文字。** 即使写的是 `/logout` 这样的命令，agent 收到的也只是一句话，不会执行它自己的命令。
- 升级到这个版本**不会**重启正在运行的会话。在旧版本里开的会话也能在群里接着回复，但只有新开的会话会主动回报状态。

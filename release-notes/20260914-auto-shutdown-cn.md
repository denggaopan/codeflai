# Codeflai 更新日志 — 0.24.0 / 2026-09-14

## 概览

本次更新新增「自动关机」：让 agent 继续跑，等最后一个跑完，Codeflai 替你把电脑关掉。

## 新功能亮点

### 没有运行中的会话时自动关机

- **需求背景：** 长任务什么时候结束不由人定。晚上开几个 agent，活儿往往后半夜就干完了，可机器还得整夜空转——剩下的事情只是「发现都停了，然后按一下电源键」而已。
- **功能描述：** 顶部栏新增一个电源按钮，就在置顶按钮左边。开启后，Codeflai 会按固定频率检查是否还有会话在运行，没有就关闭这台电脑。按钮旁边的下拉框用来选择检查频率：**1m**、**2m**、**3m**、**4m**、**5m**（默认）、**10m**、**15m**、**30m**、**1h**。
- **使用场景：** 任何无人值守的场景——过夜跑任务、一批较长的 agent 会话，或者只是人离开一会儿，不想让机器在活儿干完后又空转好几个小时。
- **操作路径：** 窗口右上角的电源按钮，紧挨着置顶按钮左侧。鼠标悬停可以看到它会做什么；开启后旁边就会出现频率下拉框。

### 十秒倒计时，随时可以叫停

- **需求背景：** 一台会自己突然关机的电脑，是不敢放心让它跑着的。坐在机器前的人，必须有办法说一句「现在别关」。
- **功能描述：** 当某次检查发现没有会话在运行时，会弹出对话框说明情况并从十秒开始倒数。**取消关机**停止本次关机，**立即关机**跳过剩下的倒计时，什么都不做则在倒数结束时关机。按 Escape 或点击对话框外侧，效果与「取消关机」相同——既然关机已经在倒数，离开对话框的每一种方式都必须是安全的那一种。
- **使用场景：** 倒计时途中人回到了机器前，或者你正看着最后一个会话结束、不想再等那十秒。
- **操作路径：** 它会自己弹出来，覆盖在当前界面之上。

## 功能优化

- **「取消」是关掉，不是「待会儿再说」：** 点击「取消关机」会把自动关机整个关掉，而不是只跳过这一轮。刚刚阻止了一次关机的人，最不希望的就是过几分钟同一个对话框又弹一次。
- **开启从不突然：** 第一次检查永远是一整个间隔之后，所以开启自动关机、或者改变频率，都不会当场把机器关掉。改频率会重新计时，选 **1m** 就是从现在起一分钟。
- **正在启动的会话也算在运行：** 终端还在启动中的会话同样会阻止关机，和运行中的会话一样。
- **设置会被记住：** 开关和频率在下次启动时恢复，所以开着自动关机的机器重启后仍会继续自己关机。即使开关关闭，选过的频率也会保留。
- **更克制的按钮：** 电源按钮在开启时只是变亮，而不是点亮成醒目的颜色；旁边出现的频率下拉框本身就是「已开启」最清楚的标志。

## 特别说明与指引

- **这是强制关机。** 在 Windows 上，各个程序会被直接关闭、不等待它们响应，所以 Codeflai 之外有未保存内容的程序不会再来问你。在 macOS 上，关机请求走的是系统自带的「关机…」，那里的程序仍可能弹出自己的保存提示。
- **「运行中」指的是会话在跑，不是它正忙。** 一个已经干完活但还开着的 agent 会话，仍然算作运行中，会阻止关机。把不再需要的会话停掉或删掉，剩下的交给自动关机。
- **如果关机被拒绝**（机器上权限不足，或有策略拦截），Codeflai 会给出提示并关闭自动关机，而不是每隔几分钟再问一次。
- **默认是关闭的**，在你亲手开启之前，一切行为与此前完全一致。

# Codeflai 更新日志 — 0.32.0 / 2026-10-10

## 概览

自动处理 issue 的会话现在会把结果告诉 Codeflai：没找到可做的 issue 时那一轮会自动清理掉，认领了 issue 的会话标题会直接写上 issue 编号和精简后的标题。

## 新功能亮点

- **需求背景：** 开着「Auto-resolve issues」的项目如果暂时没有可做的 issue，每隔半小时就会多出一条已停止的会话和一个空的 worktree，一天下来侧栏里堆几十条，得一条条手动删。
- **功能描述：** agent 列完 issue 发现没有合适的，会告诉 Codeflai「没有 issue」，Codeflai 随即删掉这一轮：会话行、它的 worktree 和启动文件一起清掉，就像你自己点了 Delete 一样。agent 要是留下了未提交的改动，这一轮会保留为已停止，不会把改动删掉。
- **使用场景：** 把项目开着跑一整夜或一整个周末，第二天侧栏里只剩真正做了事的会话。
- **操作路径：** 无需设置，开着「Auto-resolve issues」就生效。

- **需求背景：** 一轮自动处理从认领到等 test 部署往往要半小时以上，期间会话标题只有「Auto issue 月-日 时:分」，想知道它在处理哪条 issue 得点进终端翻。
- **功能描述：** agent 认领 issue 后，会话标题立刻改成「issue#编号 精简后的标题」，例如「issue#42 登录时崩溃」。标题由 agent 用 issue 原本的语言精简到 40 个字符以内，和 issue 列表对得上。
- **使用场景：** 同时开着几个项目的自动处理时，扫一眼侧栏就知道每个项目正在做哪条 issue；会话结束后也能按编号找回对应的那一轮。
- **操作路径：** 无需设置，认领后自动改名；之后仍可以手动重命名。

## 特别说明与指引

- **提示词模板多了一个占位符 `{{resultFile}}`。** 默认模板已经更新，第 1 步和第 2 步里让 agent 把结果写到这个文件。如果你改过模板，请点一次 **Reset to default**，或者把默认模板里提到 `{{resultFile}}` 的那两句补进自己的模板；没有这两句的话，会话既不会自动清理也不会改名，其余行为和之前一样。
- **列不出 issue 的那一轮会保留。** 比如 gh 没登录、仓库没有权限，agent 会在终端里说明原因然后退出，这条会话不会被清理，方便你看是哪里出了问题。
- **被清理的轮次不会弹「会话已退出」通知**，也不会留下未读标记；认领了 issue 的会话结束时照常通知。
- **换上这个版本后，之前已经在跑的自动会话不受影响**，但它们是用旧模板启动的，不会改名也不会自动清理；下一轮起就会按新规则来。

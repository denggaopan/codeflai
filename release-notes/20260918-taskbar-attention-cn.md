# Codeflai 更新日志 — 0.26.2 / 2026-09-18

## 概览

会话跑完弹通知的同时，任务栏上的 Codeflai 图标也会亮起来提醒你，和其他应用来新消息时是同一种效果。

## 新增功能

- **需求背景：** 通知会在几秒后自己消失。如果那几秒里你正好没在看屏幕，这一轮就算错过了——回头只能自己想起来去翻一眼窗口。
- **功能描述：** 弹通知的同时，Windows 任务栏上的图标会进入系统的「有新消息」状态（图标高亮、底部那条指示线变长变色），macOS 则是 Dock 图标跳动。这是系统自己画的效果，和别的应用完全一致。
- **使用场景：** 交代完任务就去忙别的，中途瞟一眼任务栏就知道跑完没有，不用切窗口确认。
- **操作路径：** 不用单独设置。它跟着设置 → 通用 → 「会话完成时通知」那一个开关走，通知会弹它就会亮。

## 特别说明与指引

- **你看一眼窗口它就灭了。** 不用手动清，也不会一直亮着烦你——切到 Codeflai 窗口的那一刻系统就把它恢复原样。
- **通知本身的规则没有变。** 什么时候弹、什么时候不弹（窗口就在你面前、你自己停掉的会话、重启后重绘的历史输出）都和之前一样。
- **和 0.26.0 那个小圆点不是一回事。** 那个是画在图标角上的一个点、需要自己清，已经在 0.26.1 去掉了；这次用的是系统原生的提醒方式。

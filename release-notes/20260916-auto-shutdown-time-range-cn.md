# Codeflai 更新日志 — 0.25.2 / 2026-09-16

## 概览

自动关机新增时间范围限制：勾选后，只有在你指定的时段内（默认 20:00 – 08:00）才会真的关机。白天会话跑完了机器也不会自己关掉，晚上才关。

## 新增功能

- **自动关机可以限定时段了。** 开启自动关机后，频率下拉右边多了一个复选框和两个时间下拉。勾上它，机器只会在这两个时间之间关闭；没勾选就和以前完全一样，任何时刻都可能关机。
- **时间从半小时一档的列表里选，不用手打。** 从 00:00 到 23:30，一共 48 个可选时刻——这是「不到晚上别关机」这种粗粒度的规则，选一下比敲四个数字快。
- **没勾选时也能改时间。** 可以先把想要的时段选好，再勾上让它生效；复选框管的是「这个时段生不生效」，不是「能不能选」。
- **默认就是过夜的那段时间（20:00 – 08:00）。** 起点比终点晚就表示跨午夜：晚上八点到第二天早上八点都算在内。起点那一刻算（20:00 会关），终点那一刻不算（08:00 整已经出了范围）。想反过来用白天也可以，比如 09:00 – 17:00。
- **时段外不关机，但检查照常。** 中午会话就全跑完的机器不会一到 20:00 就突然关掉，而是在 20:00 之后的第一次检查时关——最多比你设的起点晚一个检查间隔。
- **勾选后，电源按钮的提示会写明时段**，鼠标停上去就能确认它到底会在什么时候关机。

## 特别说明与指引

- **两个时间选成一样等于什么都不会发生。** 起止相同的时段一分钟都不包含，两个下拉会变红，电源按钮的提示也会直接说明「不会有任何关机发生」，不会让一个看起来开着的限制悄悄空转。
- **机器在时段外被唤醒不会关机。** 如果它在倒计时期间睡了过去（07:55 合盖、09:00 开盖），这次倒计时会被直接放弃，而不是醒来再给十秒——那正好落在你禁止关机的时段里。
- **取消勾选不会丢掉已填的时间**，重新勾上还是原来那两个时刻；时段和开关、频率一样跨重启保留。
- **升级后行为不变。** 这个限制默认不启用，已经在用自动关机的机器保持原样，需要时再自己勾上。
- 判断「有没有会话在跑」的规则没有变化，仍然以侧栏显示的状态为准：Done 的 agent 不算在跑，Starting… 和开着的 shell 算。

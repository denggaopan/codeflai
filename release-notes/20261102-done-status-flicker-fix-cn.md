# Codeflai 更新日志 — 0.34.1 / 2026-11-02

## 概览

修好了 agent 会话闲着时状态在「完成」和「运行中」之间反复跳动的问题，同一个会话也不会再一遍遍地弹通知。

## 问题修复

- **闲着的会话现在会稳定地显示「完成」。** 此前一个已经做完的 Claude / Codex 会话，只要你切换一下会话、切走再切回窗口，或者在它的提示符里打几个字，侧栏的状态圆点就会跳回「运行中」，过三秒再变回「完成」。原因是 agent 闲着时其实并不完全安静：切换焦点会让它重画一下提示符，打字会有回显，而 Codeflai 过去把任何一点输出都当成「又开始干活了」。现在只有这几种情况才会把会话算回「运行中」：你发出了一条指令（按下回车）、agent 自己报告正在工作，或者它持续输出了一段时间（比如转圈的进度提示）。
- **同一个会话不再反复弹通知、反复标未读。** 状态每跳回一次「完成」，过去都会被当成「又跑完了一轮」——于是一个只是闲着的会话会不断地重新变成未读，窗口不在前台时还会一条接一条地弹系统通知。随着上面的修复，现在每跑完一轮只提醒一次。

## 特别说明与指引

- **发出指令后状态会立刻变成「运行中」**，和以前一样。
- 对于不会报告自身进度的 agent（Gemini、GitHub Copilot、Cursor、Comate、Qwen Code），如果它在你没有按回车的情况下自己开始工作，状态大约会晚一秒半才变成「运行中」。
- **直接安装这版覆盖即可**，正在运行的会话不会中断，设置也会保留。
